## 🛠️ Istruzioni di Utilizzo ed Esecuzione

### 1. Clonare il repository

```bash
git clone [https://github.com/francescarossi1/Basi-di-dati-.git](https://github.com/francescarossi1/Basi-di-dati-.git)
cd Basi-di-dati-
```

### 2. Esecuzione Script SQL e Progetti Java + MySQL

🔹 **Esecuzione Script SQL (MySQL)**

```bash
mysql -u root -p < nome_file.sql
```

🔹 **Compilazione ed Esecuzione Java + MySQL (JDBC)**

```bash
javac -cp .:mysql-connector-j.jar NomeClasse.java
java -cp .:mysql-connector-j.jar NomeClasse
```
